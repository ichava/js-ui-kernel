# Translation engine

`Translator` resolves dotted message keys for seven locales; the message catalogs stay in each package.

## Locales

`LOCALES` lists English, Spanish, French, German, Portuguese, Swahili and Arabic with their endonyms and text direction. `localeDir(locale)` and `isLocale(v)` read it.

## `Translator`

Immutable: every `with*` call returns a new translator, so one mount's overrides never reach another's.

```ts
import { Translator, type Catalogs } from '@ichava/js-ui-kernel';

const MESSAGES = { en: { 'toolbar.exported': '{n} icons exported' } } as const satisfies Catalogs<'toolbar.exported'>;

const t = Translator.of(MESSAGES).withMessages('sw', serverDict).locale('sw');
t.t('toolbar.exported', { n: 12 });
```

Lookup goes requested locale, then English, then the key itself; within a locale, later override layers win over earlier ones and over the bundled catalog. `interpolate(raw, vars)` fills `{name}` placeholders and leaves an unfilled one as written.
